

# EJERCICIO: MINI-ANALIZADOR LÉXICO BÁSICO

## PLANTEAMIENTO DEL PROBLEMA
Un estudiante de ingeniería está construyendo un compilador muy básico y necesita un módulo que analice una línea de código fuente. El programa debe recorrer la cadena **carácter por carácter** usando un ciclo `while`, y construir "palabras" (tokens) temporalmente en una variable de tipo string. A medida que encuentra un espacio o un operador, debe clasificar la palabra acumulada.

**Categorías a detectar:**
1. **Palabras reservadas:** `if`, `else`, `while`, `for`, `int`, `float`.
2. **Operadores:** `+`, `-`, `*`, `/`, `=`, `<`, `>`.
3. **Variables:** Cualquier otra palabra alfanumérica que no sea reservada.

## LÓGICA A APLICAR
1. Recorrer el código con un ciclo `while` e índice `i`.
2. Si el carácter actual es una letra o número, acumularlo en una variable `token_actual`.
3. Si el carácter es un espacio o un operador:
   - Si `token_actual` no está vacío, clasificarlo (reservada o variable) e imprimirlo, luego vaciarlo (`token_actual = ""`).
   - Si es un operador, imprimirlo directamente como token de operador.
4. Al final, verificar si quedó un `token_actual` pendiente (por si el código no termina en espacio).

## ANÁLISIS EPS
| Componente | Descripción |
|------------|-------------|
| **ENTRADA** | `codigo` (Cadena): Una línea de código fuente escrita por el usuario. |
| **PROCESO** | Recorrer la cadena con `while i < len(codigo)`. Acumular caracteres alfanuméricos en `token_actual`. Al encontrar espacio u operador, clasificar el `token_actual` comparándolo con las palabras reservadas. Imprimir el token y su tipo. Los operadores se imprimen directamente. |
| **SALIDA** | Listado de tokens encontrados (en consola) con su clasificación: RESERVADA, OPERADOR o VARIABLE. |

## CÓDIGO PYTHON

```python
# ============================================================
# EJERCICIO: MINI-ANALIZADOR LEXICO BASICO
# Tema: Cadenas, Ciclos While, Condicionales
# Restricciones: Sin listas, sin diccionarios
# ============================================================

def solicitar_codigo():
    """
    FUNCION: Solicita al usuario una linea de codigo.
    SI devuelve datos (str).
    """
    codigo = input("Ingrese una linea de codigo (ej. if x = 5 + 3): ")
    return codigo


def analizar_lexico(codigo):
    """
    FUNCION: Recorre la cadena y clasifica tokens.
    SI devuelve datos (int, int, int).
    
    Parametros:
        codigo (str): Linea de codigo a analizar.
        
    Retorna:
        tuple: (total_reservadas, total_operadores, total_variables)
    
    Variables locales:
        i: Indice para recorrer la cadena.
        token_actual: Acumulador de caracteres para formar una palabra.
        total_reservadas, total_operadores, total_variables: Contadores.
    """
    i = 0
    token_actual = ""
    
    total_reservadas = 0
    total_operadores = 0
    total_variables = 0
    
    print("\n  --- TOKENS ENCONTRADOS ---")
    
    # ---- CICLO WHILE: Recorre la cadena caracter por caracter ----
    while i < len(codigo):
        caracter = codigo[i]
        
        # Si es letra o numero, lo acumulamos como parte de un token (palabra)
        if caracter.isalnum():
            token_actual = token_actual + caracter
            
        # Si es un operador
        elif caracter in "+-*/=<>":
            # Primero, si hay una palabra acumulada, la clasificamos
            if len(token_actual) > 0:
                if token_actual == "if" or token_actual == "else" or token_actual == "while" or token_actual == "for" or token_actual == "int" or token_actual == "float":
                    print("  [PALABRA RESERVADA] -> " + token_actual)
                    total_reservadas = total_reservadas + 1
                else:
                    print("  [VARIABLE]          -> " + token_actual)
                    total_variables = total_variables + 1
                token_actual = "" # Vaciamos el acumulador
            
            # Luego, imprimimos el operador
            print("  [OPERADOR]          -> " + caracter)
            total_operadores = total_operadores + 1
            
        # Si es un espacio en blanco, clasificamos el token acumulado (si existe)
        elif caracter == " ":
            if len(token_actual) > 0:
                if token_actual == "if" or token_actual == "else" or token_actual == "while" or token_actual == "for" or token_actual == "int" or token_actual == "float":
                    print("  [PALABRA RESERVADA] -> " + token_actual)
                    total_reservadas = total_reservadas + 1
                else:
                    print("  [VARIABLE]          -> " + token_actual)
                    total_variables = total_variables + 1
                token_actual = "" # Vaciamos el acumulador
                
        i = i + 1 # Incremento del indice

    # ---- Al final del ciclo, verificamos si quedo un token pendiente ----
    # (Esto pasa si el codigo no termina en espacio)
    if len(token_actual) > 0:
        if token_actual == "if" or token_actual == "else" or token_actual == "while" or token_actual == "for" or token_actual == "int" or token_actual == "float":
            print("  [PALABRA RESERVADA] -> " + token_actual)
            total_reservadas = total_reservadas + 1
        else:
            print("  [VARIABLE]          -> " + token_actual)
            total_variables = total_variables + 1

    return total_reservadas, total_operadores, total_variables


def mostrar_resumen(reservadas, operadores, variables):
    """
    PROCEDIMIENTO: Muestra el resumen del analisis.
    NO devuelve datos.
    """
    total_tokens = reservadas + operadores + variables
    
    print("\n  =========================================")
    print("  RESUMEN DEL ANALISIS LEXICO")
    print("  =========================================")
    print("  Palabras reservadas: " + str(reservadas))
    print("  Operadores:          " + str(operadores))
    print("  Variables:           " + str(variables))
    print("  -----------------------------------------")
    print("  Total de tokens:     " + str(total_tokens))
    print("  =========================================")


def main():
    """
    FUNCION PRINCIPAL: Coordina la ejecucion del programa.
    """
    print("\n" + "=" * 50)
    print("  MINI-ANALIZADOR LEXICO")
    print("=" * 50)
    
    codigo = solicitar_codigo()
    
    if len(codigo.strip()) > 0:
        res, op, var = analizar_lexico(codigo)
        mostrar_resumen(res, op, var)
    else:
        print("\n  ERROR: No se ingreso codigo.")


if __name__ == "__main__":
    main()
